Music service

Music server

The boombox streams your music from a server that speaks the Subsonic API — it appends /rest/… calls, authenticates with a fresh per-call token+salt (your password never rides in a URL), and pulls artists, albums, art, and streams. Because that boundary is a published protocol, any Subsonic-compatible server can sit at the URL. Today the supported, tested one is Navidrome — and this catalog is built to grow.

Set it up

Navidrome

Navidrome is a lightweight, self-hosted music server that exposes your library over the Subsonic API. Run it on any always-on box — a NAS, a mini-PC, an old laptop, or a cloud VPS — and the boombox streams from it on the LAN or from anywhere once you expose it. The servers/ directory ships a Docker Compose stack that stands it up for you.

1. Stand it up with Docker Compose

Copy the example env, set your media path and ports, and start the stack. The same compose file also brings up Jellyfin for video (see the video-server guide); you get both from one up.

navidrome-up.sh 
cd servers
cp .env.example .env
$EDITOR .env          # set MUSIC_DIR, VIDEO_DIR, PUID/PGID, TZ, ports
docker compose up -d          # starts Navidrome (:4533) + Jellyfin (:8096)
docker compose ps             # navidrome should show (healthy) within ~40 s

Your MUSIC_DIR is bind-mounted read-only into the container as /music, so Navidrome scans your collection but can never mutate it (ND_MUSICFOLDER=/music, ND_SCANSCHEDULE=1h). Server state — the SQLite database, playlists, stars, and play counts — lives in the named navidrome-data volume at /data, independent of the media. That volume is the thing you back up; the music you can always re-copy.

2. Create the Navidrome admin

Navidrome creates its first admin account through its own web wizard on first launch — there's no headless seed. On the LAN, open http://<host>:4533 and set a strong, unique password. Do not reuse the boombox's weak 6-digit LAN credential here — this server may end up internet-reachable. The first full scan of a typical 5–10k-album library takes a few minutes, then re-runs hourly.

3. Reach it from outside your home (optional)

On the LAN you're done — the boombox needs only a reachable URL plus credentials. To stream when the boombox travels, expose the server behind TLS. The shipped Cloudflare Tunnel overlay dials out, so you open no router ports and never reveal your home IP:

navidrome-expose.sh 
# Reach both servers from outside the home WITHOUT opening router ports
docker compose -f docker-compose.yml -f docker-compose.cloudflared.yml up -d

# Map the tunnel hostname to http://navidrome:4533 in the Cloudflare Zero Trust
# dashboard, put the tunnel token in .env as CLOUDFLARE_TUNNEL_TOKEN, then re-up.
# (Router port-forward + a reverse proxy with TLS is the other supported path.)

Exposing a media server is the highest-risk step in the project. Use a strong, unique password, keep the image patched (it's pinned on purpose — bump it deliberately), and add rate-limiting at the edge. A mesh VPN (Tailscale / WireGuard) or Cloudflare Access in front is safer than a bare public endpoint. Full walkthrough and the security rules are in HOME-SERVERS.md.

4. Point the boombox at it

Open Settings → Home Library on the touchscreen (or the LAN web UI), fill in the fields, tap Test until you see ✓ Connected, then Save:

  • Source URL — http://<host>:4533 on the LAN, or https://music.example.com once exposed.
  • Username — your Navidrome user.
  • Password — your Navidrome password. It's Fernet-encrypted at rest with a key derived from the Pi's /etc/machine-id, so moving the SD card to another Pi makes it unreadable and forces re-entry.

The on-device Setup Wizard collects the same three fields during first-run — either path writes the identical config. Once it connects, the sync chip in the chrome goes green; pin albums to a USB cache drive and they play with no server reachable at all.

Connect the boombox

The wizard does the pairing — this page just stands up the server.

You don't wire the boombox up here. A fresh device auto-launches a first-run Setup Wizard that walks through Wi-Fi, the music library, video, and remotes — the music step is exactly the URL / username / password from above, tested live before it saves. See the Setup & services reference for the wizard and every manual equivalent; don't duplicate it, just follow it once the server is up.

  • Setting up video too? The same servers/ stack runs Jellyfin — see the video-server guide.
  • Already have the boombox running? Change the source any time from Settings → Home Library.
  • The offline path is independent: pinned albums live on the USB cache drive and play with no server at all.
